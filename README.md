## About me

I'm Florent, a developer based in Belgium and the person behind
[Avenue du Web](https://avenueduweb.be).

My work ranges from web applications and business tools to software,
automation and hardware-connected systems.

I enjoy understanding how things work below the surface, which is why
my projects span both high-level application development and lower-level
topics such as networking, concurrency, processes, memory and infrastructure.

My general rule is simple:

> **Use the simplest technology that properly solves the problem.**

No unnecessary layers. No framework just because it's fashionable.
Build what is useful, understand what it does, and keep it maintainable.
